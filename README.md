HRCHAT

Projeto acadêmico da disciplina de Banco de Dados.

O HRCHAT é uma plataforma de recrutamento que aproxima candidatos
e empresas através de um chatbot automatizado.

Tecnologias:
- Oracle Database
- SQL
- BRModelo

Conteúdo:
- Modelo Conceitual
- Modelo Lógico
- Normalização de dados
- Scripts DDL
- Scripts DML
- Consultas SQL
